# Changelog

## 0.1.0

First release.

- `loupe cutout` removes the background from photos, with `--crop` and `--mask`.
- `loupe text` reads text from images and PDFs, with language hints, page selection and JSON output.
- `loupe codes` reads QR codes and barcodes.
- Every command reads files, standard input (`-`) or the clipboard (`-c`).
